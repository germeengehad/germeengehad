## 🚀 Featured Project — AlphaPulse

> **AI-Powered Trading & Market Intelligence System**

[![Live Demo](https://img.shields.io/badge/🔴_Live_Dashboard-FF4B4B?style=for-the-badge)](https://alphapulse-market-intelligence-n8gya9pdwmar6ad8gf4rxr.streamlit.app/)
[![Repo](https://img.shields.io/badge/GitHub_Repo-181717?style=for-the-badge&logo=github)](https://github.com/germeengehad/AlphaPulse-Market-Intelligence)

A **production-grade financial analytics platform** built end-to-end:

| Layer | Technology | What it does |
|---|---|---|
| **Ingestion** | Apache Airflow | Scheduled ETL pipelines for multi-timeframe market data |
| **Storage** | PostgreSQL (Dockerized) | Structured storage for 1D / 1H / 15min OHLCV data |
| **Modeling** | Scikit-learn | BUY/SELL signal prediction with backtesting engine |
| **Evaluation** | Custom backtester | Win rate, return %, max drawdown metrics |
| **Dashboard** | Streamlit | Real-time interactive visualization + model explainability |
| **Infra** | Docker + Linux | Fully containerized, reproducible deployment |
